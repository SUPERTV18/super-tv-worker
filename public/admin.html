الحماية والإعدادات

متغيرات Worker المطلوبة

اسم المتغيرالغرضمكان الإعداد
ADMIN_SECRETمفتاح لوحة الإدارةCloudflare → Worker → Settings → Variables and Secrets
GITHUB_TOKENحفظ ملف القنوات في GitHubSecret بصلاحية Contents: Read and write للمستودع
APP_SECRETمفتاح التطبيق الحالي، لا تستبدلهاتركه كما هو

أنشئ مفتاحي ADMIN_SECRET وGITHUB_TOKEN كـ Secrets في Cloudflare، وليس داخل HTML أو GitHub. استخدم GitHub fine-grained token محدودًا بمستودع SUPERTV18/super-tv-worker وصلاحية Contents للقراءة والكتابة فقط. لا تغيّر APP_SECRET الخاص بالتطبيق.

تغيير User-Agent الخاص بالسيرفر

هذه القيم خاصة بتحقق السيرفر من طلبات التطبيق وسلوك المسار القديم، وليست إعدادات User-Agent لكل قناة. تُحفظ في GitHub وتُقرأ عبر كاش مؤقت، دون استخدام KV.

حدود حالية مهمة

  • إحصائيات المشاهدين مؤقتة داخل ذاكرة نسخة Worker الحالية.
  • فحص الرابط يؤكد استجابة المصدر ونوع المحتوى فقط، وليس استمرارية الفيديو.
  • تعديل القناة يحدّث ملف GitHub؛ انتظر انتشار التغيير عبر Cloudflare Cache.
  • لا توجد سجلات تاريخية دائمة أو إيقاف/تفعيل فعلي للقنوات في هذا الإصدار.

حالة النظام

لم يتم الفحص بعد.

لم يتم دمج واجهة Cloudflare Logs API. راجع Logs / Tail في لوحة Cloudflare لمعرفة الأخطاء التفصيلية مثل PLAY_UPSTREAM_RESPONSE.
